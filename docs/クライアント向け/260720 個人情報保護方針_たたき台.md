# 個人情報保護方針（たたき台）

作成日: 2026年7月20日
ステータス: 社内たたき台（クライアント提示前にTomさんのレビュー待ち）
関連: docs/02_今後の開発環境の提案.md

## この文書の位置づけ

「実施回」対応にあたり、回答者の識別キーを氏名＋生年月日に変更する予定です。これにより、個人を特定できる情報と健康状態に関する情報（症状・欠勤有無等）が紐づくことになり、個人情報保護法上の「要配慮個人情報」に該当する可能性が高いです。要配慮個人情報の取得には、通常の個人情報よりも厳格な同意（オプトアウトではなく本人の明示的な同意）が必要とされています。

**本書はあくまで参考例であり、法的助言ではありません。** 非弁護士による具体的な法的助言は弁護士法上の非弁行為に該当するおそれがあるため、株式会社地域のミカタとして専門家レビューは行いません。「要配慮個人情報」に該当するかどうかの判断や、同意取得方法・保管期間・削除方針の適法性の確認は、クライアント側の責任において弁護士・社会保険労務士等の専門家にご確認いただくようお願いします。

## 1. 取得する情報

- 氏名（識別キー）
- 生年月日（識別キー）
- メールアドレス（任意）
- 健康状態に関する回答内容（既存のQQメソッド項目一式）

## 2. 利用目的（案）

- 同一回答者の複数回（実施回）にわたる回答を紐付け、時系列の変化を分析するため
- 部署別・年代別等の集計分析（個人を特定しない形での利用）

## 3. 同意取得方法（案）

アンケート回答フォームの冒頭に、以下のような同意チェックボックスを設置する。

> 本アンケートは氏名・生年月日を用いて複数回の回答を紐付け、健康経営の分析に利用します。個人を特定した形で第三者へ提供することはありません。上記に同意のうえ、回答を開始してください。

- 同意しない場合は回答フォームに進めない設計とする（必須同意）。

## 4. 保管期間（案）

- 契約期間中は保持し、契約終了後は原則として一定期間内（例: 1年以内）に削除する
- 具体的な期間はクライアントと合意のうえ確定する

## 5. 削除方針（案）

- 従業員本人から削除依頼があった場合、氏名・生年月日を含む個人を特定できる情報を削除し、統計データからも除外する運用を用意する
- 退職者のデータの扱いについてもクライアントと合意する

## 6. アクセス制限

- 氏名・生年月日を含む個人を特定できる情報は、`system_admin`（弊社）および `client_admin`（クライアント担当者）のみ閲覧可能とする（既存のRLS設計を踏襲）
- ダッシュボード上の集計表示は、個人が特定されない形（部署別・年代別等の集計）にとどめる

## 7. クライアントへの提示・合意の進め方（案）

1. 本たたき台をTomさんが確認・修正する
2. クライアント担当者へ「参考例」として提示する（弁護士等への確認が必要かどうかの判断・依頼はクライアント側にお任せする）
3. 同意文言・保管期間・削除方針について合意を得る
4. 合意内容を本ドキュメントに反映し、確定版とする
5. 確定後、「回答者識別方式の変更」の実装に着手する
