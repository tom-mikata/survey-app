# DBスキーマ設計書

作成日: 2026年8月10日
対象: 設問設計書 v1.1（2026年8月6日受領）への対応
ステータス: 自己レビュー済み → マイグレーション実装中

---

## 1. 設計方針

- **第1部（問1〜16）の回答** → `survey_responses` テーブルに格納
- **第2部（問17〜30）の回答** → モジュール別に別テーブルへ分離（企業ごとのON/OFFに対応するため）
- **クライアント固有の選択肢**（部署・体の不調）→ DB のマスタテーブルで管理
- **全クライアント共通の固定選択肢**（雇用形態・利用した所・日常的に使っているもの等）→ `constants.ts` で管理
- **「その他」自由記述** → 選択肢カラムとは別に `*_other text NULL` カラムで管理
- **廃止カラム** → DROP（開発環境のため）
- **`survey_round_id`** → NOT NULL。実施回登録管理画面（issue #23）が前提

## 4. RLSポリシー方針

既存テーブルと同じ方針を踏襲する。

| 操作 | system_admin | client_admin | anon（回答者） |
|---|---|---|---|
| `survey_rounds` SELECT | 全件 | 自社分のみ | 不可 |
| `survey_rounds` INSERT/UPDATE/DELETE | 可 | 不可 | 不可 |
| `survey_responses` SELECT | 全件 | 自社分のみ | 不可 |
| `survey_responses` INSERT | 可 | 不可 | **可**（回答投入） |
| 第2部テーブル SELECT | 全件 | 自社分のみ | 不可 |
| 第2部テーブル INSERT | 可 | 不可 | **可**（回答投入） |

## 5. constants.ts で管理する選択肢

| 設問 | 選択肢 |
