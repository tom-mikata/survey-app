# データ取扱い・セキュリティ注意事項

このプロジェクトでは、従業員の**氏名・生年月日**などの個人情報（PII）を扱います。開発に参加するにあたって、以下のルールを必ず守ってください。

## 1. 開発環境と本番環境は別物です

- Supabaseは「開発用」「本番用」の**別プロジェクト**として完全に分離されています。
- 普段のローカル開発では、開発用Supabaseにのみ接続します。
- 本番Supabase（実データ）へのアクセスは、`main`ブランチのマージを通じてのみ行われます。個人の判断で本番の接続情報をローカルに設定したり、本番DBに直接クエリを投げたりしないでください。

## 2. 開発中に使うデータ

- 開発・動作確認には**テストデータのみ**を使用してください。
- 実在する従業員の氏名・生年月日などを、開発用データとして入力しないでください（本人の許可なく実在する名前を使うこと自体がリスクです）。

## 3. 個人情報を外に出さない

- スクリーンショット、Slackへの投稿、エラーログの共有などで、氏名・生年月日を含む画面をそのまま貼り付けないでください。
- どうしても画面共有が必要な場合は、該当箇所をぼかす／ダミーデータに差し替えるなどしてから共有してください。

## 4. RLS（Row Level Security）について

- SupabaseのRLSポリシーは、「誰がどのデータにアクセスできるか」を制御する重要な仕組みです。
- RLSに関わる変更（テーブル構成、ポリシーの追加・変更）が必要な場合は、必ず藤田または中間さんに相談してください。自身でRLSを変更しないでください。



## 5. 迷ったら止まって確認

個人情報の扱いに関して少しでも「これでいいのかな」と思ったら、進める前に藤田か中間さんに確認してください。良かれと思った対応が後で問題になるより、先に聞いた方が確実に安全です。
