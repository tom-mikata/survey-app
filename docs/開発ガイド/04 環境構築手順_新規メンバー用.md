# 環境構築手順（新規メンバー用）

作成日: 2026年8月2日
対象: シニアエンジニア・学生エンジニアなど、新しく `survey-app` プロジェクトに参加する方
関連: `docs/03_チーム開発プロセス提案.md`（開発ルール）、`SETUP.md`

このドキュメントは、あなたのパソコンで開発を始められる状態にするための手順です。上から順番に進めてください。招待関連（GitHub/Supabase/Vercel）はプロジェクトリーダー（藤田/Tom）が事前に行っている前提です。招待メールが届いていない場合はTomさんに確認してください。

## 1. 前提: 必要なアカウント

- **GitHub**: [github.com](https://github.com) でアカウントを作成し、ユーザー名をTomさんに伝えておいてください（未作成の場合）。招待メールが届いたら承認してください。
- **Supabase**: リポジトリ招待とは別に、Supabaseからも招待メールが届きます。承認してください。
- **Vercel**: 同様に招待メールが届いたら承認してください（Vercelダッシュボードでのデプロイ確認用。必須ではありません）。
- **Claude**: Claude Codeを使うには、あなた個人のClaude（Anthropic）アカウントが必要です。[claude.com](https://claude.com) で作成し、Pro以上のプランに加入してください（Claude Codeの利用にはProプラン以上、またはAPI契約が必要です）。

## 2. 開発ツールのインストール

以下はMacを前提にしています。

### 2.1 Git

Macには標準で入っていることが多いです。ターミナルで確認してください。

```bash
git --version
```

表示されない場合は、Xcodeのコマンドラインツール（`xcode-select --install`）か、[Homebrew](https://brew.sh) 経由でインストールしてください。

### 2.2 Node.js

このプロジェクトはNode.js 20以上を前提としています。[nodejs.org](https://nodejs.org) から最新のLTS版をインストールするか、Homebrewで `brew install node` を実行してください。

```bash
node -v
npm -v
```

### 2.3 Docker Desktop

Supabaseをローカルで動かして検証する際に必要です。[Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/) からインストールし、一度起動して初回セットアップ（利用規約への同意等）を完了させてください。

### 2.4 Supabase CLI

```bash
npm install -g supabase
supabase --version
```

### 2.5 GitHub CLI（任意だが推奨）

PRやIssueをターミナルから操作できて便利です。

```bash
brew install gh
gh auth login
```

`gh auth login` を実行すると認証手順が案内されるので、指示に従ってください（ブラウザでのログインが簡単です）。

### 2.6 Claude Code

```bash
npm install -g @anthropic-ai/claude-code
claude
```

初回起動時にログインを求められるので、あなたのClaudeアカウントでログインしてください。

## 3. リポジトリの取得

```bash
git clone https://github.com/tom-mikata/survey-app.git
cd survey-app
npm install
```

## 4. 環境変数の設定

1. Supabaseダッシュボード（[supabase.com/dashboard](https://supabase.com/dashboard)）にログインし、`survey-app-dev`（テスト用）プロジェクトを開く
2. Project Settings → API から `Project URL` と `anon public` キーを控える
3. 以下を実行し、`.env.local` を作成する

```bash
cp .env.example .env.local
```

4. `.env.local` を開き、控えた値を設定する（`SUPABASE_SERVICE_ROLE_KEY` は基本的に不要ですが、必要な場合はTomさんまたはシニアエンジニアに確認してください）

## 5. ローカルでの動作確認

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開き、画面が表示されることを確認してください。`/login` からログインできるか、`/survey` でアンケートに回答できるかも確認すると安心です。

## 6. ローカルSupabaseスタックの確認（任意）

DBのマイグレーションを試したい場合は、Docker Desktopを起動した状態で以下を実行します。

```bash
supabase start
supabase db reset
```

`supabase start` の出力に表示されるURLから、ローカルのSupabase Studio（管理画面）にアクセスできます。確認が終わったら `supabase stop` で停止してください。

## 7. 開発ルールを読む

コードを書き始める前に、以下を必ず読んでください。

- `CLAUDE.md` / `AGENTS.md`（Next.js 16特有の注意点など）
- `docs/03_チーム開発プロセス提案.md`（ブランチ運用・PRレビュー・タスク管理のルール）
- `docs/01_現行モック整理.md`（現在のシステム構成の全体像）

## 8. 最初の作業の始め方

1. GitHub Issuesで自分が担当するタスクを確認する
2. `develop` から `feature/xxx`（内容が分かる名前）でブランチを作る

```bash
git checkout develop
git pull origin develop
git checkout -b feature/わかりやすい名前
```

3. 作業して、コミットする
4. `git push origin feature/わかりやすい名前` でpushする
5. GitHubでPRを作成する（baseは`develop`）
6. DBスキーマ・認証まわりの変更は、シニアエンジニアのレビューを必ず依頼する
7. レビューが通ったらマージする

分からないことがあれば、遠慮なくTomさんまたはシニアエンジニアに確認してください。
