# 環境構築手順（新規メンバー用）

対象: 新しく `survey-app` プロジェクトに参加するメンバー（Windows 前提）

このドキュメントは、あなたのパソコンで開発を始められる状態にするための手順です。上から順番に進めてください。

---

## 1. 前提：必要なアカウント

**GitHub のみ**必要です。

- [github.com](https://github.com) でアカウントを作成し、ユーザー名を Tom に伝えてください。
- リポジトリへの招待メールが届いたら承認してください。

> Supabase・Vercel のアカウントは不要です。接続情報は Tom から別途共有します。

---

## 2. 開発ツールのインストール

### 2.1 Git

[git-scm.com](https://git-scm.com/download/win) からインストーラーをダウンロードして実行してください。設定はすべてデフォルトのままで構いません。

インストール後、VS Code のターミナルで確認します。

```bash
git --version
```

### 2.2 Node.js

[nodejs.org](https://nodejs.org) から **LTS 版**のインストーラーをダウンロードして実行してください。

```bash
node -v
npm -v
```

Node.js 20 以上であることを確認してください。

### 2.3 VS Code

[code.visualstudio.com](https://code.visualstudio.com) からインストールしてください。

推奨拡張機能（インストール後に VS Code 内の拡張機能タブで検索）:
- **ESLint**
- **Prettier**
- **GitLens**

### 2.4 GitHub CLI

[cli.github.com](https://cli.github.com) からインストーラーをダウンロードして実行してください。

インストール後、VS Code のターミナルで認証します。

```bash
gh auth login
```

案内に従ってブラウザでログインしてください。

### 2.5 Claude Code

```bash
npm install -g @anthropic-ai/claude-code
```

API キーは Tom から共有します。受け取ったら、Windows のシステム環境変数に設定してください。

**設定方法：**
1. スタートメニューで「環境変数」と検索し「システム環境変数の編集」を開く
2. 「環境変数」ボタン → 「新規」
3. 変数名: `ANTHROPIC_API_KEY`、値: Tom から受け取ったキーを入力
4. OK で閉じてから VS Code を再起動

設定後、動作確認します。

```bash
claude --version
```

---

## 3. リポジトリの取得

```bash
git clone https://github.com/tom-mikata/survey-app.git
cd survey-app
npm install
```

---

## 4. 環境変数の設定

Tom から `.env.local` に設定するキーを受け取ってください。受け取ったら以下を実行します。

```bash
cp .env.example .env.local
```

`.env.local` を VS Code で開き、受け取った値を入力してください。設定が必要な項目は以下の2つです。

```
NEXT_PUBLIC_SUPABASE_URL=（Tom から受け取った URL）
NEXT_PUBLIC_SUPABASE_ANON_KEY=（Tom から受け取ったキー）
```

> `.env.local` は Git で管理されません。他の人に見せたり、Slack や GitHub に貼ったりしないでください。

---

## 5. ローカルでの動作確認

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開いて画面が表示されることを確認してください。
