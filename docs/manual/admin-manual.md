# 健康管理システム 管理者マニュアル

株式会社SO. 様向け　作成：株式会社地域のミカタ　Oct 30, 2026 版

## はじめに

このマニュアルは、健康管理システムを運用するシステム管理者（株式会社SO.様）が、アンケートの準備から結果の共有までを行うための手順書です。画面の名前やボタンの名前は、実際の画面の表記に合わせています。

### アクセス先

https://survey.so-tsuyama.co.jp

パソコンのWebブラウザ（Google Chrome、Microsoft Edgeなど）で開いてください。

### このシステムでできること

- 顧客企業（クライアント）ごとに、部署とアンケートの実施回を登録する
- 実施回ごとに回答用URLを発行し、従業員に回答してもらう
- 回答を集計し、プレゼンティーイズム・アブセンティーイズムによる労働損失額や設問ごとの結果を画面で確認する
- 2つの実施回を選んで、前回と今回の結果を比較する
- 回答データをCSVファイルで出力する
- 顧客企業の担当者に、自社の結果を閲覧できるアカウントを発行する

### このシステムでできないこと（初版）

- QRコードの発行（第3章の方法で、無料のサービスを使って作成してください）
- 回答期間の自動締め切り（実施回の終了日を過ぎても回答できます）
- 同じ人の二重回答の防止、個別の回答の修正・削除
- 従業員がログインせずに結果を見るページ、個人ごとの診断結果
- 専用の印刷レイアウト、PDFの直接出力（ブラウザの印刷機能を使います）

今後の追加開発の候補は、付録にまとめています。

### 2種類のアカウント

このシステムには、できることが異なる2種類のアカウントがあります。牧様のアカウントは「システム管理者」です。「管理者アカウント」タブでは、システム管理者は「system\_admin」、顧客企業の担当者は「client\_admin」と表示されます。このマニュアルでは「担当者」と呼びます。

|  | システム管理者（SO.様） | 担当者（顧客企業） |
| --- | --- | --- |
| 画面上の表示 | 「設定」 | 「部署・回答URL参照」 |
| 見られる企業 | すべての顧客企業 | 自社のみ |
| 企業・部署・実施回の登録、変更 | できる | できない（閲覧のみ） |
| 回答用URLのコピー | できる | できる |
| 分析結果の閲覧 | できる | できる |
| CSVの出力 | できる | できない |
| アカウントの発行・管理 | できる | できない |
| ログイン後に最初に開く画面 | 設定 | 分析結果 |

### 担当者ができること

顧客企業の担当者は、ログインすると自社の分析結果を閲覧できます。また、「部署・回答URL参照」画面で、登録されている部署と実施回、回答用URLを確認し、URLをコピーして社内に配布できます。担当者は部署や実施回を変更できないため（「部署」タブには「変更が必要な場合はシステム管理者にお問い合わせください。」と表示されます）、変更が必要なときは担当者からSO.様へ依頼が届きます。

### 用語

| 用語 | 意味 |
| --- | --- |
| クライアント（企業） | アンケートを実施する顧客企業。画面では「クライアント」と「企業」の両方の呼び方が出てきますが、同じものです |
| コード | クライアントを見分けるための英数字の記号（例：soxx）。回答用URLに含まれます |
| 実施回 | アンケートを実施する1回分の単位（例：第1回 2026年9月） |
| 第1部・第2部 | 全員が回答する問1〜16が第1部、企業ごとに表示を選べる問17〜22が第2部です |
| プレゼンティーイズム | 出勤はしているものの、体の不調で仕事の量や質が落ちている状態 |
| アブセンティーイズム | 体の不調で仕事を休んでいる状態 |
| QQメソッド | 問8〜11の回答から、プレゼンティーイズムによる損失を計算する方法 |

### 全体の流れ

1. 準備する：クライアント、部署、実施回を登録する（第2章）
2. アカウントを発行する：必要に応じて顧客企業の担当者を招待する（第4章）
3. 配布する：回答用URLをコピーして、QRコードや案内文とともに配布する（第3章）
4. 結果を見る：回答が集まったら分析結果画面で確認する（第5章）
5. 共有する：画面共有や印刷、CSVで報告する（第6章）

## 第1章　ログインと画面の見方

### ログインする

1. https://survey.so-tsuyama.co.jp を開きます。ログイン画面が表示されます。
2. 「メールアドレス」と「パスワード」を入力します。
3. 「ログイン」ボタンを押します。

&#91;image: ログイン画面\]

システム管理者は「設定」画面、担当者は「分析結果」画面が最初に開きます。「メールアドレスまたはパスワードが正しくありません」と表示されたときは、入力内容を確認してください。

### パスワードを忘れたとき・変更したいとき

1. ログイン画面の「パスワードを変更する」を押します。
2. メールアドレスを入力し、「変更用リンクを送信」ボタンを押します。メールを送信したことを知らせる表示に切り替わります。
3. 届いたメールの「パスワードリセット」リンクを押します。
4. 「新しいパスワード」を2回入力し、「パスワードを変更する」ボタンを押します。パスワードは8文字以上にしてください。
5. 「パスワードを変更しました」と表示されたら、「ログインページへ」から新しいパスワードでログインします。

&#91;image: パスワード変更：変更用リンクの送信\]

&#91;image: パスワード変更：新しいパスワードの入力\]

メール内のリンクには有効期限があります。期限が切れた場合は、手順1からやり直してください。

### 画面の見方

ログイン後の画面には、上部に共通のメニューが表示されます。

&#91;image: 共通メニュー（システム管理者）\]

| 場所 | 表示 | 押したときの動き |
| --- | --- | --- |
| 左 | 健康管理システム（ロゴ） | ログイン画面に戻ります |
| 中央 | 設定（担当者は「部署・回答URL参照」） | 設定画面を開きます |
| 中央 | 分析結果 | 分析結果画面を開きます |
| 右 | ログイン中のメールアドレス | なし（画面の幅が狭いと表示されません） |
| 右端 | ログアウト | ログアウトしてログイン画面に戻ります |

設定画面には「クライアント」「部署」「実施回」「管理者アカウント」の4つのタブがあります。担当者には「部署」「実施回」のタブだけが表示されます。

使い終わったら、必ず「ログアウト」を押してください。特に共用のパソコンでは、ログインしたままにしないでください。

## 第2章　準備する：クライアント・部署・実施回の登録

アンケートを配布する前に、クライアント、第2部の表示設定、部署、実施回の4つを、この順番で登録します。この章の操作は、システム管理者だけが行えます。

### 2-1　クライアントを登録する

1. 「設定」画面の「クライアント」タブを開きます。
2. 「コード」と「企業名」を入力します。
3. 「追加」ボタンを押します。「追加しました」と表示されれば完了です。

| 項目 | 入力のしかた |
| --- | --- |
| コード（必須） | 半角英数字の短い記号（例：acme）。回答用URLに含まれ、回答者の目にも触れます |
| 企業名（必須） | 正式な会社名（例：ACME株式会社） |

**注意：コードは登録後に変更できません。** 企業名は後から変更できますが、コードは変えられないため、登録前によく確認してください。社名がわかりにくい短い記号にしておくと、URLから企業名が推測されにくくなります。

企業名を変更するときは、一覧の「編集」ボタンを押し、企業名を書き換えて保存します。

### 2-2　第2部の表示設定をする

第2部（問17〜22）は、クライアントごとにアンケートへ含めるかどうかを選べます。一覧の「編集」ボタンを押し、「第2部の表示設定」で、含める項目にチェックを入れて保存します。

&#91;image: 「編集」を押したときの企業名と第2部の表示設定\]

| チェック項目 | 設問 | 内容 |
| --- | --- | --- |
| 問17：心の健康（K6） | 問17-1〜17-6 | 心の健康状態（Kessler心理的苦痛尺度） |
| 問18：会社のサポート（SPOS-J） | 問18-1〜18-4 | 会社から支援されていると感じているか |
| 問19〜20：仕事以外の負担 | 問19・20 | 介護・育児などの影響と支援の希望 |
| 問21〜22：運動の習慣 | 問21・22 | 運動の習慣と週あたりの日数 |

チェックを入れた項目だけがアンケートに表示され、分析結果にも集計されます。設問を増やすほど回答者の負担が増えるため、回答時間の目安（10分以内）を考えて選んでください。

設定は、回答用URLを配布する前に決めてください。回答の受付中に変更すると、回答者によって答えた設問が異なってしまいます。

### 2-3　部署を登録する

部署は、回答者が問4で選ぶ選択肢になります。

1. 「設定」画面の「部署」タブを開き、画面上部の選択欄で対象のクライアントを選びます。
2. 部署名を入力し、「追加」ボタン（またはEnterキー）を押します。
3. 必要に応じて▲▼ボタンで並び順を変えます。回答画面にはこの順番で表示されます。
4. **最後に「保存する」ボタンを押します。** 押さずに画面を離れると、変更は失われます。

&#91;image: 「部署」タブ（上部の選択欄でクライアントを選ぶ）\]

同じ名前の部署は登録できません。回答の受付が始まった後に部署名を変えると、変更前後の集計が分かれてしまうため、配布前に確定させてください。

### 2-4　実施回を作成する

1. 「設定」画面の「実施回」タブを開き、画面上部の選択欄で対象のクライアントを選びます。
2. 「実施回名」を入力します（例：第1回 2026年9月）。
3. 必要に応じて「開始日」「終了日」を入力します。
4. 「追加する」ボタンを押します。「追加しました」と表示されれば完了です。

&#91;image: 「実施回」タブの入力欄（終了日が開始日より前のときのエラー表示）\]

開始日と終了日は、記録のための表示です。終了日を過ぎても回答用URLは使え、回答も受け付けられます（第3章 3-3）。

### 初回と再評価について

システム上、実施回に「初回」「再評価」の区別はありません。分析結果画面で、比べたい2つの実施回を選んで比較します（第5章 5-6）。後で選びやすいよう、実施回名には回数と時期を入れてください（例：「第1回 2026年9月」「第2回 2027年3月」）。

## 第3章　配布する：回答用URLとQRコード

回答用URLは実施回ごとに1つ発行されます。URLにはクライアントと実施回の情報が含まれているため、必ず配布する実施回のURLを使ってください。

### 3-1　回答用URLをコピーする

1. 「設定」画面の「実施回」タブを開きます。
2. 配布する実施回の横に表示されているURLの「コピー」ボタンを押します。
3. メール、チャット、案内文書などに貼り付けます。

&#91;image: 実施回ごとの回答用URLと「コピー」ボタン（画像は開発環境のため、URLの先頭が本番と異なります）\]

URLは次の形をしています。末尾の数字が実施回を表すため、別の実施回のURLと取り違えないよう注意してください。

```
https://survey.so-tsuyama.co.jp/survey?client=（コード）&round=（実施回の番号）
```

### 3-2　QRコードを作る

このシステムにはQRコードを作る機能がありません。紙で配布する場合は、無料のQRコード作成サービスを使って、コピーしたURLからQRコードを作成してください。

1. 3-1の手順で回答用URLをコピーします。
2. QRコード作成サービスにURLを貼り付け、QRコードを画像として保存します。
3. 案内文書に貼り付けて印刷します。
4. **配布前に、印刷したQRコードをスマートフォンで読み取り、アンケートの最初の画面が開くことを確認します。**

サービスを選ぶときは、次の点に注意してください。

- URLをそのままQRコードにするもの（「静的QRコード」）を選ぶ。サービス独自の短縮URLを経由するもの（「動的QRコード」）は、有効期限が切れたり、有料化で使えなくなったりすることがあります
- 回答者に広告ページなどが表示されないものを選ぶ

### 3-3　回答期間の考え方

このシステムには、回答の受付を自動で締め切る機能がありません。実施回の終了日を過ぎても、URLを開けば回答でき、その回答はその実施回の結果に加わります。

回答期間は、次のように運用してください。

- 案内文に回答期限を書いて配布する
- 期限を過ぎたら、URLやQRコードの再配布・掲示をやめる
- 結果を報告する際は、集計した日を記録しておく（期限後の回答で人数が変わることがあるため）

### 3-4　1人1回の回答を案内する

**同じ人が何度回答しても、すべての回答がそのまま集計されます。** システムには二重回答を防ぐ機能がなく、管理者が個別の回答を削除することもできません。配布の際は、必ず「回答は1人1回」と案内してください。

### 3-5　案内文の例

配布する際の案内文の例です。会社の状況に合わせて書き換えてください。

```
従業員健康アンケートご協力のお願い

従業員の皆さまの健康づくりと働きやすい職場づくりのため、アンケートを実施します。

・回答期限：〇月〇日（〇）
・所要時間：10分程度
・回答方法：下記のURLまたはQRコードから回答してください
・回答は1人1回でお願いします（途中で画面を閉じると、入力内容は消えます）

アンケートの結果は全体の集計結果として取りまとめ、個人の回答内容が会社に公開されることはありません。

URL：（ここに回答用URL）
```

### 3-6　回答者の画面の流れ

回答者から質問を受けたときのために、回答者側の画面の流れを説明します。

1. URLを開くと、個人情報の取り扱いについての説明が表示されます。「同意して進む」を押すと回答を始められます。それ以外の方法で閉じると、アンケートを開始できません。
2. 問1〜5で、氏名、フリガナ、性別、生年月日、部署、雇用形態を入力します。部署は、2-3で登録した部署から選びます。
3. 問6以降の設問に順に回答します。画面上部に進み具合が表示され、「戻る」「次へ」ボタンで移動できます。日数や回数（問8・問9・問13）は一覧から選び、0〜10や運動日数（問10・問11・問22）は数字のボタンを押して回答します。
4. 最後の画面で「回答を送信」を押すと、「回答ありがとうございました」と表示されて完了です。

&#91;image: 最初に表示される個人情報の取り扱いの説明\]

&#91;image: 問1〜5の基本情報の入力画面\]

&#91;image: 問8〜11の画面（問10・問11は数字のボタンを押して回答）\]

&#91;image: 送信完了画面\]

回答の途中保存はできません。ブラウザを閉じたり、別のページに移動したりすると、それまでの入力内容は消えます。

問6で「健康上の問題や不調はない」を選んだ人には、問7〜11は表示されません。また、問6で不調を1つだけ選んだ人には、問7は表示されません。このように、回答者によって表示される設問の数は異なります（画面数は、第2部をすべて含めた場合は8〜9画面、第2部を含めない場合は4〜5画面）。

## 第4章　アカウントを管理する

顧客企業の担当者に自社の結果を見てもらうときは、担当者用のアカウントを発行します。アカウントの発行・変更・削除は、「設定」画面の「管理者アカウント」タブで行います。

### 4-1　担当者を招待する

1. 「管理者アカウント」タブを開きます。
2. 招待する人のメールアドレスを入力します。
3. 左の選択欄で「client\_admin」を選び、右の「クライアントを選択」でその人の会社を選びます。
4. 「招待を送信」ボタンを押すと、招待メールが送信されます。
5. 招待された人がメール内のリンクを押すと、パスワードの設定画面が開きます。パスワードを設定すると、以降はメールアドレスとパスワードでログインできます。

&#91;image: 招待メールの送信欄\]

**事前に連絡を入れてください。** 招待する前に「健康管理システムから招待メールが届く」ことを相手に伝えてください。

リンクの有効期限が切れてパスワードを設定できないときは、第1章の「パスワードを忘れたとき」の手順で設定してもらってください。

### 4-2　種類や所属クライアントを変更する

一覧から対象のアカウントを選び、種類（ロール）や所属クライアントを変更できます。担当者が別の会社に移った場合などに使います。自分自身のアカウントの種類は変更できません。

### 4-3　アカウントを削除する

退職や担当替えなどで不要になったアカウントは、すぐに削除してください。

1. 一覧で対象のアカウントの「削除」ボタンを押します。
2. 「このアカウントを削除しますか？削除すると元に戻せません。」と表示されたら、内容を確認して「OK」を押します。

削除したアカウントは元に戻せません。再び必要になったときは、4-1の手順で招待し直してください。自分自身のアカウントは削除できません。

### アカウントを管理するときの注意

- 担当者には、本人のメールアドレスで1人1つのアカウントを発行してください。複数人で1つのアカウントを使い回すと、誰が閲覧したかわからなくなります
- 担当者は所属クライアントの結果しか見られません。所属クライアントを間違えると、他社の結果を見せてしまうため、招待時に必ず確認してください
- 「管理者アカウント」タブには、登録されている全員のメールアドレスが表示されます。画面共有の際は、このタブを映さないようにしてください

## 第5章　結果を見る：分析結果画面の読み方

画面上部の「分析結果」を押すと、集計結果が表示されます（画面内のタイトルは「ダッシュボード」）。表示されるのは集計値だけで、個人の回答内容は表示されません。

### 5-1　表示する対象を選ぶ

画面上部のセレクトボックスで、表示する対象を選びます。

&#91;image: 分析結果画面の上部（表示する対象の選択欄と絞り込み）\]

| 項目 | 選び方 |
| --- | --- |
| クライアント | 表示する会社を選びます（クライアントが2社以上のときに表示） |
| 比較実施回（前回） | 前回と比べるときに選びます。比べないときは「比較なし」 |
| 表示実施回（今回） | 表示する実施回を選びます。最初は最新の実施回が選ばれています |

**クライアントは必ず1社を選んでください。** 「全クライアント」を選ぶと実施回の選択欄が表示されなくなり、実施回の選択や比較ができません。

### 5-2　部署・年代・性別で絞り込む

### 5-4　損失額の計算方法

損失額は、QQメソッドの考え方で、回答者1人ずつの回答から年間の金額を計算し、合計しています。

生産性低下による損失（プレゼンティーイズム）：

```latex
\text{問8の日数} \times 12 \times \left(1 - \frac{\text{問10}}{10} \times \frac{\text{問11}}{10}\right) \times 1\text{万円}
```

欠勤による損失（アブセンティーイズム）：

```latex
\text{問9の日数} \times 1\text{万円}
```

| 値 | 意味 |
| --- | --- |
| 問8の日数 | 直近30日間で症状があった日数。12倍して1年分に換算します |
| 問10・問11 | 症状があるときの仕事の量と質（いつも通り＝10） |
| 問9の日数 | 直近1年間で、その症状のために休んだ日数 |
| 1万円 | 1日あたりの人件費として、システムで一律に設定している金額 |

1日あたりの人件費（1万円）と、1年分への換算（12倍）は、システムで固定されています。会社ごとに変えることはできません。報告の際は、損失額が実際の賃金ではなく、この一律の単価で計算した目安であることを説明してください。

QQメソッドの解説は、画面下部の注釈にある外部サイトへのリンクから確認できます。

### 5-6　前回と今回を比較する

「比較実施回（前回）」で前回の実施回を選ぶと、比較表示に切り替わります。

- 痛みの部位の人体図は、左に前回、右に今回が並びます
- 部署ごとのグラフも、前回と今回が並んで表示されます
- 比較表示の間は「CSVダウンロード」ボタンが表示されません

&#91;image: 比較表示の痛みの部位（左が前回、右が今回）\]

### 比較するときの注意

一部の数値は、全員ではなく条件に当てはまる人だけを対象に集計しています。前回と今回で対象の人数が変わるため、数値を単純に比べると誤解を招くことがあります。

- 問7〜11は、問6で不調があると答えた人だけが回答しています。不調がある人の数が変われば、平均値などの元になる人数も変わります
- 「欠勤したことがある人」の割合は、全回答者ではなく「業務に支障がある人」の中での割合です
- 回答者の人数そのものが前回と大きく違う場合は、割合だけでなく人数も合わせて確認してください

## 第6章　共有・出力する

分析結果は、画面共有、ブラウザの印刷機能、CSVファイルの3つの方法で共有できます。従業員がログインせずに結果を見るページはないため、従業員への開示は管理者または担当者が画面を共有するか、印刷して行います。

### 6-1　画面を共有して説明する

会議室のモニターやWeb会議の画面共有で、分析結果画面を映しながら説明します。事前に5-1・5-2の手順で、見せたいクライアント、実施回、絞り込みを選んでおくとスムーズです。

画面を共有する前に、次の点を確認してください。

- 別の会社のクライアントや、見せる予定のない部署が選ばれていないか
- 「設定」画面の「管理者アカウント」タブなど、メールアドレスが表示される画面を開いていないか

### 6-2　印刷する・PDFで保存する

このシステムには専用の印刷ボタンはありません。ブラウザの印刷機能を使います。

1. 印刷したい表示（クライアント、実施回、絞り込み）にしておきます。
2. キーボードの Ctrl＋P（Macは ⌘＋P）を押します。
3. 紙に印刷する場合はプリンターを、PDFにする場合は送信先で「PDFに保存」を選びます。
4. 印刷プレビューで、グラフが途中で切れていないか確認してから印刷・保存します。

画面表示用のレイアウトをそのまま印刷するため、グラフがページの境目で切れることがあります。その場合は、印刷設定の「倍率」を小さくするか、用紙の向きを「横」にしてください。

### 6-3　CSVファイルを出力する

回答データを表計算ソフト（Excelなど）で使いたいときは、CSVファイルを出力します。

1. 分析結果画面で、クライアントと表示実施回を選びます（比較表示の間は出力できません）。
2. 「CSVダウンロード」ボタンを押します。
3. 「survey\_responses\_（実施回名）.csv」という名前のファイルが保存されます。

1行が1人の回答です。実施回名、回答日時、氏名、フリガナ、性別、年齢（生年月日から計算）、部署、雇用形態と、各設問の回答が含まれます。生年月日そのものは含まれません。第2部の表示設定をした項目は、その回答に加えて、問17（K6）の合計点と解釈、問18（SPOS-J）の合計点と平均点も出力されます。Excelでそのまま開いても文字化けしません。

現在、雇用形態の「派遣・契約・委託」は、CSVでは「契約社員」と表示されます。

### 共有するときの個人情報の注意

**CSVファイルには氏名を含む個人の回答がすべて含まれます。** 取り扱いには十分注意してください。

- CSVファイルを顧客企業に渡したり、メールに添付したりしないでください。回答者には「個人の回答内容は会社に公開されない」と説明しています
- 保存したCSVファイルは、使い終わったら削除してください
- 分析結果画面でも、少人数の部署や年代に絞り込むと、個人の回答が推測できることがあります。このシステムには、少人数の集計を隠す機能はありません。顧客企業や従業員に見せる際は、少人数の部署・年代の表示を避けるか、「社内全体」で説明してください

## 第7章　データを管理する

登録した内容の多くは後から変更できますが、クライアントのコードと個別の回答は変更できません。また、削除の操作には元に戻せないものがあります。

### 7-1　変更できるもの・できないもの

| 対象 | 変更 | 操作する場所 |
| --- | --- | --- |
| 企業名 | できる | 「クライアント」タブの「編集」 |
| 第2部の表示設定 | できる | 「クライアント」タブの「編集」 |
| コード | **できない** | — |
| 部署（追加・削除・並べ替え） | できる | 「部署」タブ |
| 実施回名・開始日・終了日 | できる | 「実施回」タブ |
| アカウントの種類・所属クライアント | できる | 「管理者アカウント」タブ |
| 個別の回答（修正・削除） | **できない** | — |

回答者が入力を間違えた場合や、同じ人が二重に回答した場合でも、管理者は回答を修正・削除できません。集計にそのまま含まれるため、3-4のとおり配布時の案内で防いでください。

### 7-2　元に戻せない操作

次の操作は元に戻せません。操作する前に、対象が正しいか必ず確認してください。

| 操作 | 消えるもの | 確認の表示 |
| --- | --- | --- |
| クライアントの削除 | そのクライアントの部署、実施回、**すべての回答データ** | あり（コードの再入力が必要） |
| 実施回の削除 | その実施回（回答がない場合のみ。下記参照） | **なし** |
| アカウントの削除 | そのアカウント | あり |

### クライアントを削除するとき

一覧の「削除」ボタンを押すと確認欄が開き、「削除すると、紐づく回答データ・部署・実施回もすべて削除されます。元に戻せません。」と表示されます。確認のためにそのクライアントのコードを入力すると「完全に削除する」ボタンが押せるようになり、押すと削除されます。やめる場合は「キャンセル」を押します。

&#91;image: クライアント削除の確認欄\]

クライアントを削除すると、過去の回答データもすべて失われ、前回との比較もできなくなります。取引が終わった場合でも、データを残す必要がないか確認してから削除してください。必要に応じて、削除の前に実施回ごとのCSVファイルを出力して保管してください。

削除しようとしてエラーになった場合は、株式会社地域のミカタにご連絡ください。

### 実施回を削除するとき

**実施回の「削除」ボタンは、押すとすぐに実行されます（確認の表示はありません）。** 押し間違えに注意してください。

- 回答が1件もない実施回は、削除されます。誤って作った実施回を消すときに使います
- 回答がある実施回は、回答データを守るため削除できません。現在、この場合にメッセージは表示されず、「削除」ボタンを押しても何も起きないように見えます

回答がある実施回を使わなくなった場合は、削除せずにそのまま残しておいてください。

### E　今後の追加開発の候補

初版に含まれていない機能のうち、運用上あると便利なものです。ご希望があれば、別途お見積りいたします。

| 候補 | 内容 |
| --- | --- |
| 二重回答の防止 | 同じ氏名・生年月日での回答を検出し、重複を防ぐ、または管理者が重複を確認・除外できるようにする |
| 回答の修正・削除 | 管理者が誤った回答や重複した回答を削除できるようにする |
| QRコードの発行 | 実施回ごとのQRコードを画面から直接発行・印刷できるようにする |
| 回答期間の自動締め切り | 終了日を過ぎたら回答を受け付けないようにする |
| 回答状況の確認画面 | 実施回ごと・部署ごとの回答数を一覧で確認できるようにする |
| 少人数の集計の非表示 | 回答者が少ない部署・年代の結果を隠し、個人の特定を防ぐ |
| 印刷用レイアウト・PDF出力 | 報告書として見やすい形で印刷・保存できるようにする |
| 1日あたりの人件費の設定 | 損失額の計算単価を企業ごとに設定できるようにする |
| 従業員向けの結果閲覧ページ | ログインせずに、URLやQRコードから全体の結果を見られるようにする |
| 個人診断チャート | 回答者本人向けのスコアや改善アドバイスを表示する |
| 5段階評価への対応 | 設問の回答方式を拡張する |
