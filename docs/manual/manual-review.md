### 要修正の詳細メモ

**#1（5-1 フィルター順序）**  
マニュアルの表は「表示実施回（今回）」が「比較実施回（前回）」より先だが、`ResultsDashboard.tsx` の実際の描画順は逆（前回セレクト → `→` → 今回セレクト）。画面を見ると「前回」が左に来て「今回」が右に来るレイアウトであり、マニュアルの表と一致しない。

**#2（3-6 画面数）**  
`buildScreenList`（`_types.ts:128-140`）から計算すると：  
- 第2部4モジュール全ON＋症状なし：8画面  
- 第2部4モジュール全ON＋症状あり：9画面  
- 第2部全OFF＋症状なし：4画面  
- 第2部全OFF＋症状あり：5画面  

「第2部をすべて含めた場合」という括弧書き内で「5〜9」とするのは、5画面になるケース（第2部なし＋症状あり）が「第2部をすべて含めた場合」という条件に該当しないため誤り。正しくは「8〜9画面」。なお「第2部なしの場合は4〜5画面」として別に言及するのが正確。

**#3（5-3 カードの内訳ラベル）**  
マニュアル：「腰痛・四肢関節・頭痛・首肩・その他疾患」  
ソース（`designTokens.ts`）：  
- `lower_back`：**腰痛**（一致）  
- `limb_pain`：**手足の痛み**（マニュアルは「四肢関節」）  
- `headache`：**頭痛**（一致）  
- `neck_shoulder`：**首・肩の痛み**（マニュアルは「首肩」）  
- `non_pain_disease`：**痛み以外の疾病**（マニュアルは「その他疾患」）
