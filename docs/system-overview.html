機能説明資料

健康経営管理システム

従業員の職業性疼痛・体の不調を把握し、QQメソッドに基づき労働損失額を可視化するウェブシステムです。企業ごとに設問モジュールをカスタマイズでき、複数回の実施を通じた経年比較もサポートします。

作成日：2026年9月 開発言語：TypeScript / Next.js インフラ：Vercel / Supabase

システム概要

本システムは、企業の従業員が抱える職業性の疼痛・不調の実態を定量的に把握し、それによって生じる労働損失額（プレゼンティーイズム・アブセンティーイズム）を可視化するためのWEBアプリケーションです。

管理者がクライアント企業・部署・実施回を設定し、URLを従業員に配布することでアンケートを収集します。回答データはリアルタイムで分析ダッシュボードに反映され、部署別・年代別・性別など多軸での集計・比較が可能です。第二部として、K6（メンタルヘルス）、SPOS-J（会社のサポート）、仕事以外の負担、運動習慣の4モジュールをクライアントごとに任意追加できます。

※ 本資料に掲載している画面表示は説明のためのイメージであり、実際のシステム画面とは一部異なる場合があります。

アンケート回答画面

6

プライバシー同意画面

/survey?client=xxx&round=n → 回答開始前モーダル

URLにアクセスした従業員が最初に目にする同意確認画面です。回答前に個人情報の取り扱いについての説明を表示し、同意した場合のみアンケートに進めます。

  • 個人情報保護方針・データ利用目的の説明
  • 「同意して進む」ボタンで回答開始
  • 同意しない場合は回答不可のメッセージを表示
  • URLパラメータ（client・round）の整合性チェック（無効URLの場合はエラー表示）
example.vercel.app/survey?client=acme&round=2
🛡
プライバシーについて

アンケートの結果は全体の集計結果として取りまとめ、個人の回答内容は会社に公開されることはありません。

調査結果は学会、論文等で公表することがあります。

アンケート ステップ1：基本情報

/survey — 問1〜5

  • 問5：雇用形態（正社員・パート・派遣・その他 から選択）
  • 全項目入力まで「次へ」ボタン無効化

アンケート ステップ2：症状選択

/survey — 問6〜7

この1か月間の体の不調を選択するステップです。複数選択可能な16の選択肢から症状を選び、複数ある場合は最も仕事に影響しているものを1つ特定します。

  • 問6：症状の複数選択（腰痛・肩こり・膝の痛みなど16選択肢）
  • 「不調はない」は排他制御（他の選択肢と同時選択不可）
  • 問7：仕事に最も影響している不調の特定（問6で複数選択時のみ表示）
  • 症状1つのみ選択時は問7をスキップして自動設定
  • 「不調はない」選択時はQQメソッドのステップをスキップ
  • 性別が男性の場合は「女性特有の不調」を自動非表示

アンケート 第二部：オプションモジュール

/survey — 問17〜22（クライアント設定で有効化）

クライアント企業ごとに有効化できる4つの追加モジュールです。設定画面でONにしたモジュールのみ第一部の後に表示されます。

  • 問21〜22：運動の習慣 — 運動習慣の有無・週あたり日数
  • 各モジュールは独立して有効化可能（全組み合わせ対応）

アンケート完了画面

/survey/complete

すべての設問に回答し「回答を送信」ボタンを押した後に表示される完了画面です。回答データがリアルタイムでデータベースに保存されます。

  • 送信完了メッセージの表示
  • 回答データはSupabase PostgreSQLにリアルタイム保存
  • 送信エラー時は詳細メッセージを表示し再試行を促す
  • 完了後はURLを閉じるよう案内

分析結果表示画面

14

分析結果ダッシュボード

/results

収集したアンケートデータを集計・可視化するダッシュボードです。職業病による労働損失額をQQメソッドで算出し、部署別・年代別・性別など多軸での分析が可能です。

  • プレゼンティーイズム率・アブセンティーイズム率の表示
  • 職業病起因の労働損失額（生産性低下＋欠勤）を万円単位で算出・表示
  • 痛みの部位をボディマップで視覚化（ホットスポット表示）
  • 部署ごとの労働損失額を積み上げ棒グラフで比較
  • 問6〜22の設問ごとの集計結果を表示
  • 2実施回の比較モード（前回→今回の変化量・差分バッジ表示）
  • 軸切り替え：部署ごと / 年代ごと / 性別ごと
  • CSVダウンロード機能（system_admin・単一実施回表示時）
  • system_admin は複数クライアントをドロップダウンで切り替え可能
