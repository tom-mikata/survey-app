Previewデプロイでログインボタンを押すと「ログイン中...」のまま固まる不具合を修正してください。

## 原因

`src/app/login/page.tsx` の `handleSubmit` 内、以下の呼び出しに try/catch がありません。

```typescript
const { error } = await supabase.auth.signInWithPassword({ email, password });
```

何らかの理由（Supabase接続先の環境変数が不正、ネットワークエラー等）でこの呼び出し自体が例外を投げると、`setLoading(false)` が実行されず「ログイン中...」の表示のまま固まります。

## やってほしいこと

1. `handleSubmit` を try/catch/finally で囲み、以下を満たすように修正する
   - 例外が発生した場合も必ず `setLoading(false)` が実行される（`finally` で行う）
   - 例外が発生した場合、画面にエラーメッセージを表示する（例: 「ログインに失敗しました。時間をおいて再度お試しください」等、既存の `error` state を使う）
   - コンソールには実際のエラー内容を出力し、原因調査ができるようにする（`console.error` 等）
2. 修正後、今回問題が起きているPreview環境で実際にログインを試し、
   - エラーメッセージが表示されるか
   - ブラウザのConsole/Networkタブに具体的なエラー内容（"Failed to fetch"、CORSエラー、401など）が出ているか
   を確認し、真の原因（環境変数の値が誤っている、Supabase側のURL Configurationの問題等）を特定・報告してください。
3. 原因が判明したら、Preview環境の環境変数設定（値の誤り、余分な引用符・空白等）かコード側かを切り分けて対応してください。
4. 修正後、PRを作成してください（`develop`向け）。
