# オンボーディング 第2回アジェンダ（予告）

日程・実施形式（対面 or リモート）は別途調整します。

## 目的

- 環境構築で残った疑問を解消する
- プロジェクトの背景・全体構造・ルールを理解し、最初の実務タスクに着手できる状態にする

## タイムテーブル（目安・60〜90分）


| 内容            | 目安時間   | 補足                               |
| ------------- | ------ | -------------------------------- |
| 環境構築の振り返り     | 5〜10分  | 起動確認と質問拾い上げ                      |
| 背景・アーキテクチャ確認  | 10〜15分 | 事前に見てもらった提案書・設問設計書・構成図の補足        |
| Git運用ルール確認    | 15分    | ブランチ運用、PR〜mainマージの流れ             |
| データ取扱い・セキュリティ | 15分    | 個人情報の扱い、開発/本番Supabaseの分離、RLSの重要性 |
| 初回タスク・Q&A     | 15分    | 最初の実務タスクの確認と、自由な質疑応答             |


## 実施形式について

- 可能な限り対面で調整しますが、リモートになる可能性もあります。
- リモートの場合、「データ取扱い・セキュリティ」の項目はビデオオン必須で実施します。
- Git運用ルールの部分は画面共有でPR作成を実演する予定です。

## この回のゴール

- [ ] Gitのブランチ運用ルールを理解し、実際にPRを1つ作成できる状態になる
- [ ] 個人情報を扱うプロジェクトであることの重みと、守るべきルールを理解している
- [ ] 最初の実務タスクに着手できる状態で終わる
