# 初回タスクリスト

オンボーディング初日〜最初の数日で取り組んでもらう内容です。上から順に進めてください。

## Step 1：環境構築（第1回）

- [ ] README.mdの手順に沿ってローカル環境をセットアップ
- [ ] `.env.example`を参考に、開発用Supabaseの接続情報を設定（藤田から共有）
- [ ] ローカルで開発サーバーが起動し、画面が表示されることを確認
- [ ] 既存のアンケート機能・ダッシュボードを一通り自分で触ってみる

## Step 2：コードベースを読む（第1回〜第2回）

- [ ] ディレクトリ構成をひと通り眺める（README記載の構成を参照）
- [ ] アンケート画面 → 集計・分析画面の一連の流れを、コード上で追ってみる
- [ ] わからない用語・実装は遠慮なくメモしておき、まとめて質問する

## Step 3：Gitワークフローを実践する（第2回〜）

- [ ] `feature/xxx`ブランチを1つ作成
- [ ] ごく小さな変更（表示テキストの修正、ボタンの色調整など）を加える
- [ ] PRを作成し、Vercel Preview URLで動作確認
- [ ] 藤田にレビュー依頼 → 承認後マージ

これは「作業内容そのもの」よりも「開発〜レビュー〜マージの一連の流れに慣れる」ことが目的です。

## Step 4：最初の実務タスク

issue #20「アンケートフォームの設問対応」を2人で分担して実装します。

### 事前準備（ブランチ作成）

PR #28 が develop にマージ済みであることを確認してから、以下を実行してください。

```bash
git checkout develop
git pull origin develop
```

次に、**自分の担当に応じて**ブランチを作成します。

**学生A の場合：**
```bash
git checkout -b feature/issue-20a-survey-form-basic-to-qq
```

**学生B の場合：**
```bash
git checkout -b feature/issue-20b-survey-form-pain-to-end
```
