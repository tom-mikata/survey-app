# Claude Codeの接続手順

事前に個別発行されたAPIキーを使って、Claude Codeを使えるようにする手順です。上から順に進めてください。

## 前提

- 自分専用に発行されたAPIキー（`sk-ant-...`で始まる文字列）を受け取っていること
- このキーは自分専用です。もう一人の学生のキーと共有・使い回しはしないでください

## 手順

1. **Claude Codeをインストール**

   PowerShellで以下を実行します。
   ```
   npm install -g @anthropic-ai/claude-code
   ```

2. **APIキーを環境変数として設定**

   PowerShellで以下を実行します（`sk-ant-...`の部分は自分に発行されたキーに置き換えてください）。
   ```
   setx ANTHROPIC_API_KEY "sk-ant-..."
   ```

3. **ターミナルを開き直す**

   `setx`の変更は、新しく開いたターミナルにしか反映されません。一度PowerShellを閉じて、開き直してください。

   開き直した後、以下を実行してキーの値が表示されれば設定成功です。
   ```
   $env:ANTHROPIC_API_KEY
   ```

4. **プロジェクトフォルダでclaudeを起動**

   ```
   cd プロジェクトのパス
   claude
   ```

   環境変数が設定されていれば、ブラウザのログイン画面は出ず、代わりに「このキーを使用しますか？」という確認が表示されます。

5. **キーを承認**

   表示された確認で承認（Yes等）を選びます。これで設定は完了です。以降は、このプロジェクトフォルダ内で`claude`と入力すればすぐに使えるようになります。

## 注意事項

- このAPIキーは**プロジェクトのファイル（`.env.local`など）には絶対に書かないでください**。あくまでPCの環境変数として設定するものです
- Slack・GitHub・チャットなどにキーの文字列を貼らないでください
- うまく接続できない場合は、手順のどこで止まったかを添えて連絡してください
